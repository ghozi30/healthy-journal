# Nurture - Healthy Journal & Wellness Tracker

A modern, responsive web application for health journaling and daily wellness tracking.

## Features
- **Daily Health Journaling**: Log mood, thoughts, daily activities, and wellness notes.
- **Hydration Tracker**: Monitor daily water intake with visual progress.
- **Nutrition & Calorie Counter**: Keep track of daily meals and calories.
- **Activity & Workout Log**: Track exercise duration, types, and calories burned.
- **Sleep Quality Tracker**: Record sleep duration and quality.
- **Interactive UI**: Built with Tailwind CSS, Alpine.js, and modern glassmorphism aesthetics.

## Tech Stack
- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Alpine.js** (for reactive state and interactivity)
- **FontAwesome & Google Fonts**

## Getting Started
Open `index.html` or `healthy.html` in any modern web browser or run it with Live Server.
